Which ICO Size Should I Choose?

ICO icons are most useful when they include the sizes your operating system and browser will actually ask for. When you pick multiple sizes, they are embedded in one ICO file and the OS picks the best match.

  • 16 pxTaskbar, window titles, legacy browser favicons.
  • 32 pxStandard favicon, folder and file icons.
  • 48 pxWindows desktop and HiDPI favicons.
  • 64 pxToolbar and taskbar icons on Windows.
  • 128 pxApp shortcuts and Retina-display icons.
  • 256 pxHighest fidelity — Steam, itch.io, and Windows 4K use it.

Frequently Asked Questions

Are my WebP images uploaded to a server?

No. This is a fully client-side tool. Your files are read, resized, and packaged entirely inside your browser using the HTML5 Canvas API and the JSZip library. Nothing is ever transmitted over the internet.

Is the converter free?

Yes. There is no sign-up, no watermark, and no fee for processing or downloads. The website is supported by display advertising so the tool can stay free forever.

How many files can I convert at once?

There is no fixed limit. Because processing is local, your only constraints are your browser's memory and your device's performance. Progress updates live, so the UI never appears frozen during large batches.

Which ICO size should I choose?

For website favicons, 32×32 is the safe standard and 48×48 improves HiDPI screens. For Windows desktop, launcher, or game icons, 256×256 provides the highest fidelity and downscales well. Selecting multiple sizes embeds them all in one ICO so Windows and browsers can pick the best match.

Can I convert multiple WebP files at once?

Yes. Drag and drop or select many WebP files, choose your sizes, and convert. Every resulting ICO icon is downloaded either individually or as one ZIP file.

Does transparency work?

Yes. ICO output is written as 32-bit PNG-compressed entries, which preserves the alpha channel. Keep the background set to Transparent to keep transparency, or flatten to white or black for favicons that need a solid backdrop.

Can I use the ICO as a favicon?

Yes. Use the Favicon Generator mode to produce favicon.ico (16/32/48) plus PNGs at 16, 32, 48, 192 and 512 px, together with copy-paste HTML <link> tags. Modern browsers also accept PNG favicons, so the package covers old and new alike.

Does it work offline after the page loads?

Yes. Once the page and the JSZip library have loaded, conversion runs entirely locally. No further network requests are needed while you convert files.
