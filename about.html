🎯 Why We Built It

We are a small team of web developers and independent game developers who grew tired of the daily friction of preparing icons for Windows games, launchers, and websites. Converting WebP assets into ICO format — one file at a time, through upload-based converters — was slow, insecure, and risky for unreleased game art.

Modern game engines and art pipelines produce WebP for its excellent compression. But Windows, browsers, and many launcher systems still need the classic ICO container for app icons, taskbar icons, and favicons. We wanted a zero-hassle bridge between the two, in bulk, without uploading art to a stranger's server.

⚙️ How the Tool Works

Everything runs in your browser using the HTML5 Canvas API to decode and resize each WebP, and the JSZip library to package your converted ICO files into a single ZIP for easy download.

Because no backend server or database is involved, the tool costs nothing to host, and your files stay 100% private by design.
